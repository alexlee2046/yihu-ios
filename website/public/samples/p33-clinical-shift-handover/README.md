# 夜班换班行政交接空白表 / Night-shift swap administrative checklist

用于医院临时换班后的非患者行政核对：排班版本、跨午夜起止、岗位覆盖、既有审批和接班反馈。
For non-patient administrative checks after a hospital shift swap: roster version, midnight boundaries, coverage, existing approval and receiving feedback.

- 中文：checklist.zh.json；English: checklist.en.json。两表包含相同的十二项，不需将两表当作两次交班。
- Both files contain the same twelve checks; translations are not separate handovers.
- 这是空白人工工作表，不是排班导入格式、审批记录或一呼原生功能。网页及下载文件不会接收或保存填写内容。
- This is a blank manual worksheet, not a roster import format, approval record or native Yihu feature. The page and files do not receive or save entries.
- null / unfilled 表示未填写，不代表通过、无风险、无待办、未发生或不适用。核对范围有明确依据才可填写。
- null / unfilled means unfilled, not passed, safe, empty, never happened or not applicable. Record only supported scope.
- checked_reference 仅放获准的最小引用；checked_scope 只写已核范围；unresolved 保留未解问题。不填患者资料、员工联系方式、凭据、完整排班表或私有正文。
- checked_reference is a minimal authorized reference; checked_scope is the verified scope; unresolved retains gaps. No patient data, staff contacts, credentials, full rosters or private content.
- 另存前核医院规则、设备、位置与访问权限。录音另需许可。目标工作台可能保存或同步内容，本机识别不是全程不离机保证。
- Before saving, check hospital rules, device, location and access. Recording needs separate permission. Destinations may store or sync content; local recognition is not an end-to-end on-device guarantee.
- 提议不等批准、草稿不等发送、服务回执不等接班确认。失败或不确定先查原目标，不盲重发或代签。
- Proposal is not approval; draft is not sent; service receipt is not staff acceptance. Check the original destination before acting on failures or uncertainty; do not blindly resend or acknowledge for others.
- 患者病情、医嘱、用药及紧急处置直接走医院规定的临床与升级渠道。本表不提供临床建议、人员资质判断或法律/合规认证。
- Patient condition, orders, medication and urgent care use hospital-required clinical and escalation channels. No clinical advice, credential assessment or legal/compliance certification.
