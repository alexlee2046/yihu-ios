<h2 id="first-answer">Meeting Minutes is a handoff prompt template, not completed native minutes</h2>

The organization Picker selects instruction without rewriting stored transcript. Direct insertion can prepend it; short tray text includes instruction/body, long tray material uses Markdown body plus separate instruction. Radar draft save passes transcript directly. These are not identical payloads, and a selected label establishes no generated minutes, filled owners/dates or destination execution.

## Different from brief fields, multi-note review and candidate admission

Briefs concern editorial fields, multi-note concerns material scope, candidates concern targets. Here **template request versus product and actual outlet text** matter. No summarizer or real note handoff ran.

## Synthetic template note

Choosing Meeting Minutes without destination output establishes a prompt choice, not completed minutes. A Radar draft carrying only original text does not include template instructions merely because the Picker showed them.

Review editorial outputs separately from recordings, unknowns and authorized scope. A request to omit nothing is no completeness proof. No real material was generated/shared and no minutes/CSV/transcoding/approval service is added.

## FAQ

<h3 id="faq-1">Does choosing minutes edit saved transcription?</h3>

No rewrite occurs here; the Picker selects instruction.

<h3 id="faq-2">Does native ASR perform the organization task?</h3>

Not from this template. Prompt construction is not a minutes product.

<h3 id="faq-3">Do all three outlets carry the same text?</h3>

No. Direct/tray can include instruction; Radar passes transcript, and long tray material includes a file.

<h3 id="faq-4">Is the long attachment a transcoding service?</h3>

No. UTF-8 Markdown text material is not universal audio/file transcoding.

<h3 id="faq-5">Does the template guarantee owners/dates?</h3>

No. Review result/original/unknown without inventing people/deadlines.

<h3 id="faq-6">Was summarization or handoff run?</h3>

No. Static template/payload review only, without real model/destination operations.
