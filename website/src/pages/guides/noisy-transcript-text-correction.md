<h2 id="first-answer">先做一个有用的检查</h2>

先回放能核对的原音频，检查人名、数字和否定词。把没有依据的部分标成待确认，再在实际可编辑的草稿或工具中修订。

## 按这个顺序做

1. 保留原文与音频，对照不确定的词，不靠句子流畅程度猜事实。
2. 在已有、获准可编辑的位置修订；保留要确认的问题。
3. 查看目的地是否已有旧稿，以及剪贴板和附件分别是哪一版。
4. 检查修改后的草稿，再决定发送；已有交接结果不明时先停下核对。

<div role="region" aria-label="按情况选择下一步" tabindex="0">

| 遇到的情况 | 你可以怎么做 | 继续前确认 |
|---|---|---|
| 原生保留文字 / 原音频 | 保留核对依据。 | 改字不会改变原音频。 |
| 修订稿 | 写清要采用的句子。 | 用实际已有的编辑工具处理。 |
| 目的地旧草稿 | 检查那里显示的版本。 | 按目标服务自己的保存/同步规则修改。 |
| 剪贴板 / 已有附件 | 分别检查副本。 | 不要假定其他位置一起更新。 |

</div>

## FAQ

<h3 id="faq-step-1">能自动把所有副本更新吗？</h3>

分别检查目的地和附件；一呼不提供跨副本自动更新。

<h3 id="faq-step-2">改字后可以重新交接吗？</h3>

先打开目的地已有草稿，核对或修改那一份；上次结果还不清楚时，不要再次交接。

<h3 id="faq-step-3">数字或人名听不清怎么办？</h3>

保留待确认，向原资料或参与者核实，不补出一个看起来合理的答案。

<h3 id="faq-step-4">修订后能证明降噪效果吗？</h3>

人工修订与原始识别成绩不同，具体设备和环境需要单独试录。
